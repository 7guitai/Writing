# ライティングエージェント ワークフローガイド

## 概要

このガイドでは、SEO特化型ライティングエージェントの使い方と記事作成の全体フローを説明します。

---

## クイックスタート

### 1. 記事作成を依頼する

以下の情報を指定してください：

```
キーワード: SEO対策 初心者
ターゲット: ブログを始めたばかりの20-30代
目的: 情報提供
文字数: 5000文字
トーン: カジュアル
テンプレート: blog-post
```

### 2. エージェントの応答フロー

```
[ユーザー] キーワードと条件を入力
    ↓
[エージェント] キーワード分析
    - 検索意図の判定
    - サブKW / LSI / 共起語の設計
    - 競合差別化ポイントの提案
    ↓
[エージェント] アウトライン提示
    - 見出し構成（H1-H3）
    - 各セクションの概要
    - 推奨文字数配分
    ↓
[ユーザー] アウトライン確認・修正依頼
    ↓
[エージェント] 記事本文を執筆
    - テンプレートに沿った構成
    - SEOルールに準拠したライティング
    - メタ情報の生成
    ↓
[エージェント] SEO自己チェック
    - seo-analyzer の基準で自己評価
    - スコアと改善点を提示
    ↓
[ユーザー] レビュー・修正依頼
    ↓
[エージェント] 修正・最終版の納品
```

---

## ワークフロー詳細

### Phase 1: キーワード分析

エージェントに以下を伝えると、自動的にキーワード分析を行います。

**入力例:**
```
「プログラミング 独学」で記事を書きたい。
ターゲットは未経験の社会人。情報提供記事で5000文字程度。
```

**エージェントの出力:**
```
【キーワード分析結果】

■ メインKW: プログラミング 独学
■ 検索意図: Informational（知りたい）
■ 推奨テンプレート: ハウツー記事

■ サブKW:
  - プログラミング 独学 始め方
  - プログラミング 独学 何から
  - プログラミング 独学 期間

■ LSIキーワード:
  - プログラミング言語、学習サイト、環境構築
  - ポートフォリオ、転職、スクール

■ 共起語:
  - 初心者、挫折、無料、教材、Python

■ ロングテール:
  - プログラミング 独学 社会人 何から始める
  - プログラミング 独学 挫折しない方法
```

### Phase 2: アウトライン設計

キーワード分析に基づき、見出し構成を提案します。

**エージェントの出力例:**
```
【アウトライン案】

H1: プログラミング独学の始め方｜未経験から3ヶ月で基礎を身につける完全ロードマップ

H2: プログラミング独学は本当にできる？
  H3: 独学で成功した人の共通点
  H3: 独学 vs スクール、どっちがいい？

H2: 独学を始める前に決めること
  H3: 目的を明確にする
  H3: プログラミング言語を選ぶ
  H3: 学習計画を立てる

H2: プログラミング独学の5ステップ
  H3: ステップ1: 環境構築
  H3: ステップ2: 基礎文法を学ぶ
  H3: ステップ3: 写経で手を動かす
  H3: ステップ4: オリジナル作品を作る
  H3: ステップ5: ポートフォリオにまとめる

H2: 独学で挫折しないための3つのコツ
  H3: コツ1: 小さく始める
  H3: コツ2: コミュニティに参加する
  H3: コツ3: アウトプット前提で学ぶ

H2: おすすめ学習リソース
  H3: 無料サイト
  H3: 有料教材
  H3: 書籍

H2: よくある質問

H2: まとめ

推奨文字数配分:
- リード文: 300文字
- 各H2セクション: 600-800文字
- FAQ: 400文字
- まとめ: 200文字
- 合計: 約5,000文字
```

### Phase 3: 記事執筆

アウトラインが承認されたら、本文を執筆します。

**依頼方法:**
- 「このアウトラインで書いてください」→ 全文執筆
- 「セクション2だけ書いてください」→ 部分執筆
- 「もっとカジュアルなトーンで」→ トーン調整

### Phase 4: SEO分析

記事完成後、SEO分析エージェント（`agents/seo-analyzer.md`）の基準で自動チェックします。

**依頼方法:**
```
この記事をSEO分析してください。
メインキーワード: プログラミング 独学
```

### Phase 5: 修正・納品

分析結果に基づき修正を行い、最終版を納品します。

## Tips

### 良い記事を書くためのコツ

1. **結論ファースト**: 読者は答えを求めている。最初に結論を示す
2. **具体例は必須**: 抽象的な説明だけでは読者は離脱する
3. **データで裏付け**: 数字があると説得力が格段に上がる
4. **読者目線で推敲**: 「この説明で初心者に伝わるか？」を常に問う
5. **内部リンク設計**: 記事単体でなく、サイト全体のSEOを意識する

### よくある失敗

- キーワードの詰め込みすぎ → 不自然な文章は逆効果
- 見出しだけ立派で中身が薄い → 各セクションに価値ある情報を
- まとめが手抜き → 最後まで読んだ読者への感謝を込めて
- 誰に書いているか不明 → ターゲットを明確に設定する
- 更新日が古い → 定期的にリフレッシュする
