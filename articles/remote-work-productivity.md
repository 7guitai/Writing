# リモートワークで集中力アップ！今日から使える3つのコツ

「家だとなかなか集中できない」って感じたことありませんか？通勤がなくなって楽になった反面、オンとオフの切り替えが難しいですよね。実は、ちょっとした工夫で生産性がぐっと上がるんです！

**① 作業スペースを固定する**
「この席に座ったら仕事モード」という場所を決めましょう。リビングのソファだとどうしてもだらけてしまいがち。専用スペースを作るだけで脳が自然と切り替わりますよ！

**② 25分集中×5分休憩を繰り返す**
「ポモドーロテクニック」という方法です。要するに、短いサイクルで脳をこまめにリフレッシュさせる方法ですね。タイマーをセットするだけなので、すぐ始められます。

**③ 朝に「今日やること3つ」を書き出す**
タスクが多すぎると何から始めればいいか迷ってしまいますよね。朝イチに優先度の高いことを3つだけ決めておくと、迷いなくスタートできます。シンプルなToDoが一番効くんです。

小さな積み重ねが、大きな変化につながります。ぜひ今日から試してみてください！
