# リモートワークで集中力アップ！今日から使える3つのコツ

「家だとなかなか集中できない」って感じたことありませんか？通勤がなくなって楽になった反面、オンとオフの切り替えが難しいですよね。気づいたらダラダラと時間が過ぎていた…なんて経験、きっとあるはず。実は、ちょっとした工夫で生産性がぐっと上がるんです！

**① 作業スペースを固定する**
「この席に座ったら仕事モード」という場所を決めましょう。リビングのソファだとどうしてもだらけてしまいがち。専用スペースを作るだけで脳が自然と切り替わりますよ！できればデスクの上は仕事道具だけにするのがベストです。

**② 25分集中×5分休憩を繰り返す**
「ポモドーロテクニック」という方法です。要するに、短いサイクルで脳をこまめにリフレッシュさせる方法ですね。スマホのタイマーをセットするだけで始められるので、難しく考えなくて大丈夫です。

**③ 朝に「今日やること3つ」を書き出す**
タスクが多すぎると何から始めればいいか迷ってしまいますよね。朝イチに優先度の高いことを3つだけ決めておくと、迷いなくスタートできます。シンプルなToDoが一番効くんです。付箋1枚でも十分ですよ！

小さな積み重ねが、大きな変化につながります。まず1つだけ、今日から試してみてください！
